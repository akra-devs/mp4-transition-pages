처리방침

통화필름은 사용자가 직접 선택한 미디어를 개인 보관용 영상으로 만드는 Android 앱입니다. 선택한 파일과 AI 자막은 기기 안에서 처리하고, 대량 만들기에는 Google 보상형 광고를 사용합니다.

01

처리하는 정보

앱은 사용자가 Android 시스템 파일 선택기에서 직접 고른 오디오 파일 또는 오디오 트랙이 있는 영상 파일과 다음 정보를 처리합니다.

  • 파일명, MIME 형식, 파일 크기, 수정 시각과 무결성 확인용 SHA-256
  • 사용자가 입력한 제목, 상대 이름과 전화번호
  • Android 시스템 연락처 선택기에서 사용자가 직접 고른 한 건의 이름과 전화번호
  • 녹음 시각과 길이, 생성한 표지와 MP4 영상

영상 파일을 입력하면 오디오 트랙만 처리합니다. 이 정보는 앱 기능을 제공하기 위해 기기 안에서만 사용하며 앱 전용 저장공간에 보관합니다.

02

녹음·자막의 수집·전송·공유

앱은 계정이나 개발자 운영 서버를 사용하지 않습니다. 선택한 미디어, 연락처 정보, 통화 기록, 자막과 결과 영상을 개발자 또는 광고 사업자 서버로 수집·전송하지 않습니다.

사용자가 공유를 요청할 때마다 앱 전용 cache/callfilm_shares/<share-id>/recording.mp4에 고유한 임시 사본을 만듭니다. Android 공유 창에서 사용자가 선택한 대상에만 이 사본의 임시 읽기 권한을 줍니다. 통화필름은 이 사본을 원격 서버로 전송하지 않습니다.

갤러리 저장도 사용자가 직접 실행할 때만 수행합니다. 외부로 내보낸 파일은 해당 수신 앱이나 저장 서비스의 정책에 따라 처리됩니다.

03

보상형 광고와 Google 처리 정보

앱을 시작할 때 Google User Messaging Platform으로 광고 개인정보 상태를 확인합니다. Google Mobile Ads 광고는 대량 만들기에서 사용자가 광고 보고 시작하기를 선택한 경우에만 표시합니다. 보상을 받으면 앱을 종료할 때까지 대량 만들기를 다시 이용할 수 있습니다. 광고를 닫거나 불러오기에 실패하면 목록은 시작되지 않습니다.

Google Mobile Ads SDK는 광고 제공, 분석과 부정 사용 방지를 위해 다음 정보를 자동으로 수집하고 Google과 공유할 수 있습니다.

  • IP 주소와 IP 주소에서 추정한 대략적인 위치
  • 앱 실행, 탭과 광고 시청 같은 제품 상호작용
  • 앱·SDK 실행 시간, 멈춤 비율과 에너지 사용량 같은 진단 정보
  • 앱 세트 ID 등 기기·계정 식별자

앱은 Android 광고 ID 권한을 제거해 광고 ID 수집을 비활성화하고, 개인 맞춤이 아닌 광고를 요청합니다. 위 정보는 전송 중 TLS로 암호화됩니다. 녹음 파일, 연락처, 통화 기록, 자막, 표지와 결과 영상은 광고 SDK에 전달하지 않습니다.

Google의 처리와 보관에는 Google 개인정보처리방침과 Google Mobile Ads Data safety 안내가 적용됩니다. 필요한 지역에서는 Google 동의 양식이 표시되며, Google이 개인정보 선택 항목을 요구하는 경우 앱의 설정 > 광고 개인정보 선택에서 다시 열 수 있습니다.

04

권한

앱은 통화 기록, 연락처 전체 읽기, 마이크 또는 전체 저장소 권한을 요청하지 않습니다. 파일과 연락처는 Android 시스템 선택기에서 사용자가 직접 고른 항목만 읽습니다. 완성 영상 저장은 MediaStore 또는 시스템 저장 위치 선택기를 사용합니다. 인터넷 권한은 광고 개인정보 상태 확인과 사용자가 선택한 보상형 광고에 사용합니다.

05

안전한 처리

선택한 파일과 통화 기록은 다른 일반 앱이 직접 읽을 수 없는 Android 앱 전용 저장공간에 보관합니다. 자동 자막을 켜면 오디오 트랙을 최대 5분 단위로 나눠 포함된 자막 생성 모델로 기기 안에서 순서대로 처리합니다.

원격 자막 API, API 키, 오디오 업로드 또는 원격 모델 다운로드를 사용하지 않습니다. 민감한 녹음이 다른 앱의 오디오 재생 캡처 대상이 되지 않도록 차단합니다. Android 클라우드 백업과 기기 간 전송도 비활성화합니다. 사용자가 공유나 저장을 직접 요청한 경우에만 Android 시스템 기능을 통해 결과 파일을 내보냅니다.

06

보관과 삭제

통화 기록은 사용자가 앱 안에서 삭제하거나 앱을 제거할 때까지 앱 전용 저장공간에 보관됩니다. 개발자 서버에 보관되는 사본은 없습니다.

  • 앱 안에서 기록을 삭제하면 해당 원본 복사본, 메타데이터, 표지, AI 자막과 결과 영상을 삭제합니다.
  • 읽을 수 없는 기록은 자동 삭제하지 않습니다. 보관함의 복구 경고에서 사용자가 명시적으로 확인한 경우에만 삭제합니다.
  • Android가 공유용 임시 사본을 더 일찍 회수할 수 있습니다. 남아 있는 24시간 이상 지난 항목은 다음 앱 시작 또는 공유 때 정리되므로 정확히 24시간이 되는 즉시 삭제되는 것은 아닙니다.
  • 갤러리나 다른 앱으로 내보낸 복사본은 해당 위치에서 별도로 삭제해야 합니다.

앱을 제거하면 Android가 앱 전용 데이터도 삭제합니다.

광고 SDK가 처리하는 정보는 개발자 서버에 저장되지 않으며 개발자가 개별 사용자를 식별해 보관하거나 삭제할 수 없습니다. 사용자는 Android 설정의 광고 개인정보 제어와 Google 계정의 개인정보 도구를 이용할 수 있습니다.

07

이용자 책임

통화 녹음과 공유 관련 법률 및 동의 요건은 국가와 지역에 따라 다릅니다. 사용자는 정당하게 보유하고 필요한 동의를 받은 녹음만 사용해야 합니다.

01

파일 선택과 지원 형식

통화필름이 통화를 직접 녹음하나요?

아니요. 통화필름은 통화기록, 연락처 전체 목록 또는 마이크에 접근하지 않습니다. 사용자가 이미 정당하게 보유한 오디오 파일이나 오디오 트랙이 있는 영상 파일을 직접 선택해 새 영상으로 만드는 도구입니다.

표지에 전화번호를 표시할 때는 Android 시스템 연락처 선택기에서 사용자가 고른 연락처 한 건만 기기 안에서 사용합니다.

어떤 기기와 파일을 지원하나요?

Android 7.0(API 24) 이상의 64비트 ARM 기기를 지원합니다. M4A, AAC, MP3, WAV, MP4, MOV 파일을 선택할 수 있습니다. MP4와 MOV는 영상 화면을 가져오는 입력이 아니며 오디오 트랙만 처리합니다. 실제 디코딩 가능 여부는 파일 형식, 오디오 트랙과 기기의 미디어 코덱에 따라 달라질 수 있습니다.

녹음 파일은 어떻게 선택하나요?

보관함의 시작하기 또는 새 영상을 누르면 Android 시스템 파일 선택기가 열립니다. 앱은 사용자가 직접 고른 파일만 앱 전용 저장공간으로 복사하며 전체 저장소를 탐색하지 않습니다.

대량 탭에서는 한 번에 최대 20개를 고를 수 있습니다. 대량 만들기를 시작하려면 안내 시트에서 광고 보고 시작하기를 누르고 보상형 광고의 보상을 받아야 합니다. 보상을 받으면 앱을 종료할 때까지 다시 광고를 보지 않습니다. 광고를 닫거나 불러오기에 실패하면 목록은 시작되지 않습니다. 현재 Pro 판매는 준비 중이며 앱 안에 결제나 외부 구매 링크는 없습니다.

파일별 이름·녹음 시각·길이를 확인한 뒤 공통 표지·품질·자막 설정을 적용합니다. 자막 생성과 영상 인코딩은 한 파일씩 순서대로 진행합니다. 실패한 항목이 있어도 다음 항목을 계속 처리하며, 앱이 백그라운드로 이동하면 현재 항목을 안전하게 중단하고 남은 목록을 유지합니다.

제목과 상대 이름이 자동으로 입력되는 이유는 무엇인가요?

Galaxy 통화 녹음처럼 파일명이 이름_YYMMDD_HHMMSS 또는 이름_YYYYMMDD_HHMMSS 형식이면 이름과 녹음 시각을 제안합니다. 파일명에 상대 번호만 있으면 이름은 알 수 없는 상대로 두고 번호 입력란에 자동으로 채웁니다.

번호는 표지에 전화번호 표시를 선택한 경우에만 영상 표지에 표시됩니다.

02

AI 자동 자막

자동 자막은 서버를 사용하나요?

아니요. 자동 자막을 켜면 기기에 준비된 한국어 음성 인식 모델이 선택한 파일을 기기 안에서 처리합니다. 오디오는 최대 5분 단위로 순서대로 처리하며 마이크, API 키, 업로드 또는 원격 자막 서버를 사용하지 않습니다. 앱의 인터넷 권한은 광고 개인정보 상태 확인과 사용자가 선택한 보상형 광고에만 사용됩니다.

어떤 자막 모델을 사용할 수 있나요?

모델 선택 항목은 Base, Small, Medium, Turbo이며 설치된 모델만 사용할 수 있습니다. Base가 기본값이고 현재 릴리스 앱에는 Base만 포함합니다. 나머지는 검증용 빌드 또는 향후 모델 팩 대상입니다.

Medium과 Turbo는 고성능 기기를 대상으로 하며 Base보다 처리 시간, 메모리와 발열 부담이 커질 수 있습니다. 한국어 정확도가 항상 더 좋다고 보장하지 않습니다. 첫 실행에는 포함된 모델을 앱 전용 저장공간에 준비하므로 추가 저장공간과 시간이 필요합니다.

03

영상 만들기

완성 영상의 형식은 무엇인가요?

결과물은 1280×720 H.264 영상과 AAC-LC 48kHz 오디오가 들어 있는 MP4입니다. 절약(15fps), 균형(20fps), 고화질(24fps) 중 선택할 수 있으며 각 프리셋은 앱이 안전한 bitrate와 채널 구성을 정합니다. 기기 인코더가 이 계약을 만들 수 없으면 손상된 완성본으로 저장하지 않고 실패를 안내합니다.

영상 만들기 중 다른 앱을 열어도 되나요?

렌더링은 포그라운드에서만 진행됩니다. 다른 앱으로 이동하거나 통화필름이 백그라운드로 가면 미완성 파일을 남기지 않고 작업을 취소합니다. 앱으로 돌아와 다시 만들기를 실행할 수 있습니다.

영상 만들기에 실패하면 어떻게 하나요?

이 기기는 1280×720 H.264/AAC 영상 만들기를 지원하지 않습니다 가 표시되면 필수 인코더가 없는 기기이므로 다른 Android 기기에서 다시 시도해야 합니다.

그 밖의 실패라면 기기 저장공간을 확보하고 다른 앱을 닫은 뒤 다시 시도하세요. 처음 인코더를 여는 과정의 일시적인 실패는 즉시 재시도로 해결될 수 있습니다. 이전 완성 영상이 있다면 실패한 재렌더가 덮어쓰지 않으며, 해당 카드에서 갤러리 저장과 공유를 계속 사용할 수 있습니다.

04

저장·공유·삭제

갤러리에 저장한 파일은 어디에 있나요?

Android 10 이상에서는 보통 Movies/Callfilm에 저장됩니다. Android 7~9에서는 시스템 저장 위치 선택기에서 사용자가 위치를 정합니다. 갤러리 앱이나 Google Photos가 새 파일을 표시하는 시점은 기기마다 다를 수 있습니다.

통화 기록을 삭제하면 모든 복사본이 사라지나요?

앱 안의 기록을 삭제하면 원본 복사본, 메타데이터, 표지와 결과 영상을 삭제합니다. 이미 갤러리, 문서 저장 위치 또는 다른 앱으로 내보낸 복사본은 해당 위치에서 별도로 삭제해야 합니다. 앱을 제거하면 Android가 앱 전용 데이터도 삭제합니다.

공유용 임시 사본은 언제 삭제되나요?

공유할 때마다 앱 전용 cache/callfilm_shares/<share-id>/recording.mp4에 고유한 임시 사본을 만듭니다. Android가 더 일찍 정리할 수 있고, 남아 있는 24시간 이상 지난 항목은 다음 앱 시작 또는 공유 때 삭제합니다. 정확히 24시간에 즉시 삭제되는 것은 아닙니다.

Android 공유 창에서 사용자가 선택한 대상만 이 사본을 임시로 읽을 수 있으며, 통화필름은 이를 원격 전송하지 않습니다.

05

개인정보와 이용 책임

파일이 서버로 전송되나요?

녹음 파일, 연락처, 자막, 표지와 결과 영상은 개발자나 광고 서버로 전송되지 않습니다. 자동 자막과 영상 변환도 기기 안에서 처리합니다. 통화필름은 공유용 임시 사본을 원격 전송하지 않으며, 사용자가 공유나 갤러리 저장을 직접 요청한 경우에만 Android 시스템 기능으로 결과 파일을 내보냅니다.

다만 앱은 Google Mobile Ads와 User Messaging Platform을 사용합니다. 앱 시작 때 광고 개인정보 상태를 확인하고, 사용자가 대량 만들기 광고를 선택하면 IP 주소, 제품 상호작용, 진단 정보와 광고 ID를 제외한 기기·계정 식별자가 Google에 전송될 수 있습니다. 자세한 내용은 개인정보 처리방침에서 확인할 수 있습니다.

광고를 보지 않으면 어떤 기능을 사용할 수 있나요?

단건 영상 만들기, 기기 내 AI 자동 자막, 보관함, 재생, 갤러리 저장과 공유는 광고 없이 사용할 수 있습니다. 최대 20개 파일을 차례로 처리하는 대량 만들기만 보상형 광고 게이트를 거칩니다. 광고 보기 전 보상과 데이터 처리 내용을 안내하며, 사용자가 직접 선택하지 않은 전면 광고는 표시하지 않습니다.

통화 녹음과 공유가 합법인가요?

법률과 동의 요건은 국가와 지역에 따라 다릅니다. 필요한 동의를 받고 본인이 정당하게 보유한 녹음만 사용해야 합니다. 통화필름은 개별 상황에 대한 법률 자문을 제공하지 않습니다.

파일 선택 AI 자막 영상 만들기 저장·삭제 개인정보

통화필름이 통화를 직접 녹음하나요?

아니요. 통화필름은 통화 기록, 연락처 전체 목록 또는 마이크에 접근하지 않습니다. 사용자가 이미 정당하게 보유한 오디오 파일이나 오디오 트랙이 있는 영상 파일을 직접 선택해 새 영상으로 만드는 도구입니다. 표지에 전화번호를 표시할 때는 Android 시스템 연락처 선택기에서 사용자가 고른 연락처 한 건만 기기 안에서 사용합니다.

어떤 기기와 파일을 지원하나요?

Android 7.0(API 24) 이상의 64비트 ARM 기기를 지원합니다. M4A, AAC, MP3, WAV, MP4, MOV 파일을 선택할 수 있습니다. MP4와 MOV는 영상 화면을 가져오는 입력이 아니며 오디오 트랙만 처리합니다. 실제 디코딩 가능 여부는 파일 형식, 오디오 트랙과 기기의 미디어 코덱에 따라 달라질 수 있습니다.

녹음 파일은 어떻게 선택하나요?

보관함의 시작하기 또는 새 영상을 누르면 Android 시스템 파일 선택기가 열립니다. 대량 탭에서는 한 번에 최대 20개를 고를 수 있습니다. 앱은 사용자가 직접 고른 파일만 앱 전용 저장공간으로 복사하며 전체 저장소를 탐색하지 않습니다.

여러 파일 만들기는 파일별 이름·녹음 시각·길이를 따로 확인하고 공통 표지·품질·자막 설정을 적용합니다.

대량 만들기를 시작하려면 안내 시트에서 광고 보고 시작하기를 누르고 보상형 광고의 보상을 받아야 합니다. 보상형 광고의 보상은 현재 선택한 대량 목록과 그 목록의 실패 재시도에만 적용됩니다. 보상 전에 광고를 닫으면 해당 목록은 취소되고, 광고를 표시할 수 없으면 해당 목록은 광고 없이 진행합니다. 목록을 비우고 새 파일을 선택하면 보상형 광고 확인이 다시 필요합니다. 광고 개인정보 선택이 필요하면 광고 설정, 일시적으로 광고를 불러오지 못하면 다시 시도를 선택할 수 있습니다. 이 버전에서는 대량 만들기 광고를 사용할 수 없습니다가 표시되면 지원 페이지에서 최신 안내를 확인해 주세요. Pro 상품은 판매하지 않으며, 제공 여부도 정해지지 않았습니다. 앱 안에 결제나 외부 구매 링크는 없습니다.

자막을 켜면 각 파일의 오디오를 최대 5분 단위의 음성 구간으로 나눠 순서대로 처리합니다. 자막 생성과 영상 인코딩은 한 번에 한 파일씩 실행하며, 한 파일을 마친 뒤 다음 파일로 이동합니다. 손상되거나 만들기에 실패한 항목이 있어도 다음 항목을 계속 처리합니다. 다른 앱으로 이동하면 현재 작업을 멈추고 남은 목록을 유지합니다.

제목과 상대 이름이 자동으로 입력되는 이유는 무엇인가요?

Galaxy 통화 녹음처럼 파일명이 이름_YYMMDD_HHMMSS 또는 이름_YYYYMMDD_HHMMSS 형식이면 이름과 녹음 시각을 제안합니다. 파일명에 상대 번호만 있으면 이름은 알 수 없는 상대로 두고 번호 입력란에 자동 채웁니다. 번호는 표지에 전화번호 표시를 선택한 경우에만 영상 표지에 표시됩니다. 이름이 있는 파일은 직접 입력하거나 시스템 연락처 선택기에서 번호를 고를 수 있습니다.

영상 형식은 무엇인가요?

결과물은 1280×720 H.264 영상과 AAC-LC 48kHz 오디오가 들어 있는 MP4입니다. 절약(15fps), 균형(20fps), 고화질(24fps) 중 선택할 수 있으며 각 프리셋은 앱이 안전한 bitrate와 채널 구성을 정합니다. 기기 인코더가 선택한 계약을 만들 수 없으면 손상된 완성본으로 저장하지 않고 실패를 안내합니다.

영상 만들기 중 다른 앱을 열어도 되나요?

영상 만들기는 통화필름 화면이 보이는 동안에만 진행됩니다. 다른 앱으로 이동하면 미완성 파일을 남기지 않고 작업을 취소합니다. 앱으로 돌아와 다시 만들기를 실행할 수 있습니다.

자동 자막은 서버를 사용하나요?

아니요. 자동 자막을 켜면 기기에 준비된 한국어 음성 인식 모델이 선택한 파일을 기기 안에서 처리합니다. 오디오는 최대 5분 단위로 순서대로 처리하며 마이크, API 키, 음성 업로드 또는 원격 자막 서버를 사용하지 않습니다. 인터넷은 광고·광고 개인정보 처리, 이용 분석·오류 진단과 사용자가 요청한 추가 모델 다운로드에 사용됩니다.

Base, Small, Medium은 기존처럼 앱 설치와 함께 제공되며 Base가 기본값입니다. Base는 앱에 포함되고 Small·Medium은 Google Play install-time asset pack으로 설치됩니다. 첫 실행에는 선택한 모델을 앱 전용 저장공간에 준비하므로 추가 저장공간과 시간이 필요합니다.

설정에서는 고성능 실험용 Turbo 모델 약 574MB를 추가로 받을 수 있습니다. 사용자가 받기를 누르면 Hugging Face와 파일 배포망에 연결하며 데이터 요금이 발생할 수 있습니다. 녹음이나 자막은 전송하지 않습니다. 다운로드 완료 후 자막 모델에서 선택할 수 있고 기본 모델이 자동으로 바뀌지는 않습니다. 취소·실패 후 다시 받을 수 있으며 중단된 다운로드는 처음부터 시작합니다.

Small·Medium·Turbo는 Base보다 처리 시간·메모리·발열 부담이 커질 수 있으며, 한국어 정확도가 항상 더 좋다고 보장하지 않습니다. 특히 Turbo는 저사양 기기에서 매우 느릴 수 있습니다.

외부 자막을 불러오거나 내보낼 수 있나요?

네. 스튜디오의 자막 관리에서 UTF-8 SRT 또는 WebVTT 파일을 불러올 수 있습니다. 파일은 최대 5MiB와 10,000개 대화 구간까지 지원하며, 확인 화면에서 형식·구간 수와 경고를 본 뒤 활성화합니다. 기존 AI 자막은 삭제되지 않아 다시 돌아갈 수 있습니다. 자막을 바꾸면 기존 완성 영상에는 바로 반영되지 않으므로 영상 다시 만들기 필요 안내에 따라 새 영상을 만드세요.

활성 자막은 SRT 또는 WebVTT로 내보낼 수 있습니다. 자막 파일에는 대화 내용이 그대로 들어가므로 확인 안내를 읽은 뒤 Android 시스템 저장 위치를 직접 고릅니다. 불러오기·내보내기와 대화 타임라인에는 별도 광고가 없습니다.

AI 자막을 저장하기 전에 무엇을 확인해야 하나요?

AI 자막은 음질에 따라 다르게 인식될 수 있습니다. 완성 화면의 재생 버튼으로 자막 내용을 확인한 뒤 저장하거나 공유해 주세요. 결과가 맞지 않으면 자막을 끄고 영상을 다시 만들 수 있습니다.

영상 만들기에 실패하면 어떻게 하나요?

  • 이 기기는 1280×720 H.264/AAC 영상 만들기를 지원하지 않습니다가 표시되면 필수 인코더가 없는 기기이므로 다른 Android 기기에서 다시 시도합니다.
  • 기기의 영상 처리 기능에서 오류가 발생했습니다가 표시되면 먼저 다시 시도합니다. 반복되면 앱을 완전히 닫았다가 다시 실행하고, 그래도 계속되면 기기를 재시작합니다.
  • AI 자막을 만들지 못했습니다가 표시되면 자막 끄고 영상 만들기로 바로 계속하거나 자막 다시 시도를 선택할 수 있습니다.
  • 영상 처리 중 오류가 발생했습니다가 표시되면 먼저 다시 시도합니다. 계속 실패하면 여유 저장공간과 입력 파일 재생 여부를 확인한 뒤 개인정보가 없는 오류 문구와 기기 정보를 지원 페이지에 남겨주세요.

이전에 완성된 영상이 있다면 실패한 재렌더로 덮어쓰지 않으며, 편집 중에도 이전 완성 영상 카드에서 갤러리 저장·공유를 계속 사용할 수 있습니다.

갤러리에 저장한 파일은 어디에 있나요?

Android 10 이상에서는 보통 Movies/Callfilm에 저장됩니다. 새 파일명은 연락처 이름이나 전화번호를 넣지 않은 CallFilm_YYYYMMDD_HHmmss.mp4 형식입니다. Android 7~9에서는 시스템 저장 위치 선택기에서 사용자가 위치를 정합니다. 갤러리 앱이나 Google Photos가 새 파일을 표시하는 시점은 기기마다 다를 수 있습니다. Android 7~9에서 저장 위치 선택기를 열지 못했다는 안내가 표시되면 기기의 파일 앱이 설치되어 있고 사용 설정되어 있는지 확인한 뒤 다시 시도하세요.

통화 기록을 삭제하면 모든 복사본이 사라지나요?

통화 기록 삭제는 앱 안의 원본 복사본, 메타데이터, 표지, AI 자막과 결과 영상 및 가져온 최종 자막 문서를 삭제합니다. 처음 선택한 파일은 그대로 남습니다. 외부 자막 원본도 그대로 남습니다. 공유용 임시 사본은 아래 정리 주기를 따릅니다. 이미 갤러리, 문서 저장 위치 또는 다른 앱으로 내보낸 복사본은 해당 위치에서 별도로 삭제해야 합니다. 앱을 제거하면 Android가 앱 전용 데이터도 삭제합니다.

공유용 임시 사본은 언제 삭제되나요?

공유할 때마다 앱 전용 cache/callfilm_shares/<share-id>/recording.mp4에 고유한 임시 사본을 만듭니다. Android가 더 일찍 정리할 수 있고, 남아 있는 24시간 이상 지난 항목은 다음 앱 시작 또는 공유 때 삭제합니다. 정확히 24시간에 즉시 삭제되는 것은 아닙니다. 사용자가 Android 공유 창에서 선택한 대상만 이 사본을 임시로 읽을 수 있으며, 통화필름은 이를 원격 전송하지 않습니다.

파일이 서버로 전송되나요?

녹음 파일, 연락처, 자막, 표지와 결과 영상은 개발자나 광고 서버로 전송되지 않습니다. 자동 자막과 영상 변환도 기기 안에서 처리합니다. 통화필름은 공유용 임시 사본을 원격 전송하지 않으며, 사용자가 공유나 갤러리 저장을 직접 요청한 경우에만 Android 시스템 기능으로 결과 파일을 내보냅니다.

다만 앱은 Google Mobile Ads와 User Messaging Platform을 사용합니다. 앱을 시작할 때 광고 개인정보 상태를 확인하며 이 과정에서 Google과 통신할 수 있습니다. 기존 개인정보 선택이 광고 요청을 허용하면 Google Mobile Ads는 기존 이용자의 시작 화면, 보관함·스튜디오·대량·설정 탭 상단과 단일 영상 3회 완성 지점에서 광고를 요청할 수 있습니다. 시작 광고는 앱 실행당 최대 한 번이며 완료 광고는 최소 2분 간격입니다. 수동 선택이 없는 광고 지점은 새 동의 양식을 열지 않고, 광고가 준비되지 않으면 작업을 막지 않습니다. IP 주소와 대략적인 위치, 제품 상호작용, 진단 정보와 광고 ID 등 기기·계정 식별자가 Google에 전송될 수 있습니다.

Android 앱은 Google Analytics for Firebase와 Firebase Crashlytics도 사용합니다. Analytics에는 앱·세션·기기 같은 기본 측정 정보와 앱 준비, 네 개의 고정 화면 코드, 영상 내보내기 완료만 기록합니다. Crashlytics에는 충돌·ANR, 제한된 스택과 고정 사유 코드·기술 상태만 보냅니다. 두 서비스 모두 녹음·자막· 파일명·제목·상대 이름·전화번호·검색어·사용자 ID를 앱 정의 값으로 받지 않습니다. 자세한 내용은 개인정보 처리방침을 확인합니다.

광고를 보지 않으면 어떤 기능을 사용할 수 있나요?

앱의 핵심 영상 만들기는 광고가 준비되지 않아도 계속 사용할 수 있습니다. 보관함·스튜디오·대량·설정 탭 상단에는 배너 광고가, 기존 이용자의 시작 화면과 단일 영상 3회 완성 지점에는 빈도를 제한한 전면 광고가 표시될 수 있습니다. 최대 20개 파일을 차례로 처리하는 대량 만들기는 별도 보상형 광고 게이트를 거칩니다. 광고 보기 전 보상과 데이터 처리 내용을 안내합니다.

통화 녹음과 공유가 합법인가요?

법률과 동의 요건은 국가와 지역에 따라 다릅니다. 필요한 동의를 받고 본인이 정당하게 보유한 녹음만 사용해야 합니다. 통화필름은 개별 상황에 대한 법률 자문을 제공하지 않습니다.

어디로 문의하나요?

공개 지원 페이지 https://akra.kr/mp4-transition-pages/support/에서 자주 묻는 질문을 확인합니다. 개인정보나 공개하기 어려운 내용이 포함되지 않은 문의는 help@akra.kr로 보낼 수 있습니다. 재현 과정을 공개해도 되는 문제라면 https://github.com/akra-devs/mp4-transition-pages/issues/new에 공개 문의를 작성합니다. 기기 모델, Android 버전, 문제가 발생한 단계와 화면에 표시된 오류 문구처럼 개인정보가 없는 재현 정보만 적어주세요. 녹음 파일, 전화번호, 연락처나 실제 통화 내용은 첨부하거나 입력하지 않습니다.

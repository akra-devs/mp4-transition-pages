대표 기능

AI 자동 자막

포함된 Base Q5 음성 인식 AI로 오디오를 기기 안에서 처리해 영상에 자막을 직접 입힙니다.

대량 만들기

최대 20개의 녹음을 고르고 보상형 광고의 보상을 받은 뒤, 한 파일씩 안전하게 자막과 영상을 만듭니다.

갤러리 저장

완성한 MP4를 확인한 뒤, 사용자가 직접 선택한 순간에만 갤러리에 저장합니다.

로컬 보관

원본 복사본, 편집 정보, AI 자막과 완성 영상은 다른 일반 앱이 읽기 어려운 앱 공간에 둡니다.

녹음 업로드 없음

가입 없이 사용하며, 녹음을 개발자 서버에 업로드하지 않습니다. 앱에는 광고가 표시될 수 있고, 여러 파일 만들기의 보상형 광고는 직접 선택합니다.
